---

## Repository Structure

The repository is organized into the following folders:

### `base-files`
Contains the foundational code snippets and test implementations for the basic functions of each robot subsystem or block.

Examples include:
- Motor Control
- Line Sensor
- Wall Sensor

These files are mainly intended for:
- Initial testing
- Prototyping
- Learning and debugging individual robot functions before full integration

---

### `header-files`
Contains the header (`.h`) files used in the actual MPLAB project.

These files define:
- Function prototypes
- Macros
- Constants
- Library inclusions
- Global declarations

---

### `source-files`
Contains the source (`.c`) files used and compiled in the final MPLAB project build.

These files implement:
- Robot logic
- Peripheral drivers
- State machines
- Navigation behavior
- Integrated sensor control
